2. 처리 방식

• 그룹별 손절 횟수는 [Backtest Report] 블록의 Group Name + 총 손절 회수에서 읽음
• [Backtest Report] 백테스팅 합산 결과는 제외
• 손절 시각은 [Close] 블록 안의 datetime + □ LOSS + - GROUP 조합에서 읽음
• 미리보기 없음
• 저장 형식은 CSV이며, Chrome 계열에서는 가능하면 디스크에 바로 스트리밍 저장
